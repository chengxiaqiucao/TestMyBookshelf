**版本**：v1.0

**目标**：补齐迭代遗留功能、修复历史缺陷、引入用户系统与借阅管理，并完成中英文支持。

## 0. 文档约定

- 本文档只描述**应当实现的功能与应当修复的缺陷**，作为开发验收依据。
- 本迭代**新注入的测试故障不属于需求**，不写入本文档；其编号、现象与定位统一记录在 `BUG_LIST.md`（本地文件，不推送远端），待实现完成后按实际表现增补。

- 修复范围：`sprint0` 缺陷**全量修复**；`sprint1` 缺陷**按影响程度挑选修复**，其余转入后续迭代（见第 4 节）。

## 1. 功能改进

### 1.1 用户系统

**用户故事 1：注册与登录**
- As a 图书收藏者, I want 注册账号并登录, so that 我的图书与借阅记录可以被归属于我。
- 验收标准：
  1. 注册必填用户名、密码、邮箱；用户名唯一，重复注册返回明确中文提示。
  2. 密码必须使用 `bcrypt`/`passlib` 哈希存储，**任何接口与页面均不得出现明文密码**。
  3. 登录成功建立会话，会话 ID 在登录前后重新生成；未登录访问受保护页面跳转登录页。
  4. 登录态校验统一接入依赖注入，不允许存在"定义了但未挂载"的认证函数。

**用户故事 2：角色与数据隔离**
- As a 系统使用者, I want 只能看到自己的数据, so that 他人隐私不被泄露。
- 验收标准：
  1. 图书、阅读计划、借阅记录均带 `owner_id`，查询默认按当前用户过滤。
  2. 通过 URL 直接访问他人资源 ID 时返回 403，而非返回数据或 404 之外的异常。

### 1.2 图书借阅管理

**用户故事 3：借出与归还**
- As a 图书收藏者, I want 记录图书借出与归还, so that 我可以追踪书籍流向。
- 验收标准：
  1. 图书状态为"在库"时方可借出；借出后状态自动变为"借出"，并生成一条借阅记录（借出人、借出日期、应还日期）。
  2. 归还操作更新借阅记录的归还日期与状态，并同步将图书状态恢复为"在库"。
  3. 状态为"待购买"的图书不可借出，前端禁用按钮且后端二次校验，返回提示"待购买图书不可借出"。
  4. 超过应还日期未归还的记录标记为"已超期"，列表以红色标签展示。

**用户故事 4：借阅历史与首页活动**
- As a 系统使用者, I want 查看最近借阅/归还活动, so that 我快速了解图书动态。
- 验收标准：
  1. 首页展示最近 5 条借阅/归还记录，含图书封面缩略图、操作类型、时间，点击可跳转图书详情。
  2. 提供借阅历史页，支持按时间范围与状态筛选。

### 1.3 中英文支持

**用户故事 5：界面语言切换**
- As a 使用者, I want 在中英文之间切换, so that 不同语言习惯的用户都能使用系统。
- 验收标准：
  1. 所有页面文案、表单标签、错误提示、状态枚举展示值均提供中英文双语。
  2. 语言选择持久化（Cookie 或用户偏好字段），刷新与跳转后保持。
  3. 日期与数字格式随语言切换（中文 `YYYY-MM-DD`，英文 `MM/DD/YYYY`；价格符号同步切换）。
  4. 不允许出现"部分页面已翻译、部分仍为中文"的遗漏。

### 1.4 迭代遗留功能补齐

**用户故事 6：统计与分析**
- As a 数据分析者, I want 使用完整的统计能力, so that 我能分析阅读习惯。
- 验收标准：
  1. 图表库统一使用 ECharts；提供月度阅读量折线图、计划完成率柱状图、24 小时阅读热力图。
  2. 支持按时间范围与图书分类筛选；支持将统计结果导出为 CSV（UTF-8 BOM，Excel 可直接打开）。
  3. 后端提供聚合查询接口，前端移动端使用简化视图。
  4. 所有统计指标口径唯一：首页与统计页的同名指标必须来自同一计算函数。

**用户故事 7：实时更新与交互**
- 首页数据通过 WebSocket 推送更新，无需手动刷新即可反映新增/归还/计划进度变化。
- 封面支持拖拽上传并实时预览（缩略图 200×300）；计划时间线可视化；任务状态支持看板式拖拽管理。
- 说明：看板拖拽管理若工期不足，按第 4 节转入后续迭代，不作为本迭代验收阻塞项。
